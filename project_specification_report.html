2. Security Architecture

Blue Pillar incorporates enterprise-grade security logic to cater to sensitive administrative actions and guard against malicious web activities.

  • Row Level Security (RLS): Direct database access controls ensuring that Public users can only read authorized property listings, while complete Write/Delete pipelines are rigorously gated to Authenticated Admin UUIDs.
  • Server Action Rate Limiting: Implements active rate-limit logic protecting contact form endpoints from DDOS attacks and unauthorized spam looping.
  • Payload Sanitization: Employs strict server-side schema parsing using Zod before any input reaches the database layers.
  • Defensive Auth Strategies: HTTP-Only Secure cookies prevent access token theft through XSS injections.

3. Database Schema & Migrations

The database maintains strict relational integrity inside PostgreSQL via Supabase. Below defines the core table schemas and their responsibilities:

Table Name Core Responsibility Key Features
profiles Identity Management Tied to `auth.users`. Grants 'admin' roles to specific emails.
properties Listing Catalog Holds titles, pricing, spatial data, `property_status`, and analytical triggers (views/clicks). Uses `buildium_id` mapping.
property_images Media Handling One-To-Many relationship to properties storing persistent asset bucket URLs.
leads Inquiry Routing Routes messages systematically into categorizes: Owner, Tenant, Maintenance, Renovation.
maintenance_orders Operations Tracks ongoing tickets spanning from Pending to Completed against properties.

4. Advanced Software Features & Capabilities

The system expands far beyond a simple landing page into an end-to-end management toolkit.

Intelligent Property Syncing (Buildium Integration)

A server-orchestrated CRON system directly queries Buildium's Open API. It natively ingests new properties, syncs rented/unlisted property lifecycles, and resolves dual-entry friction by treating Buildium as the singular Source-of-Truth.

SEO & Performance-Optimized Public Funnel

Rental browsers experience a lightning-fast catalog with dynamic client-side pagination, strict sorting (Newest/Price/Popular), and dynamic route rendering. RPC DB increments discreetly record market interest per-listed asset.

Command Center Dashboard

Authenticated users have exclusive access to secure internal routing featuring multi-dimensional stat tracing via Recharts, consolidated lead management, and quick-action toolsets.

Streamlined Lead Intake System

User inputs are intercepted, validated, committed to the cloud database, and synchronously fired into Resend via highly styled HTML templates to immediately notify management of prospective tenants or owners.
